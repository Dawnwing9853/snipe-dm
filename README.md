# snipe-dm

Claude Code skill ที่ส่งแชท Facebook, Messenger หรือ Instagram ให้ไปถึงตรงเวลาระดับมิลลิวินาที (อิงเวลา GMT+7) เหมาะกับงานแย่งคิว เช่น จองโต๊ะร้านที่เปิดรับทางแชทตอนเที่ยงคืน หรือส่งข้อความวันเกิดให้ถึงตอน 00:00:00 พอดี

*A Claude Code skill that sends a Facebook / Messenger / Instagram DM from Microsoft Edge on Windows at an exact GMT+7 time, to the millisecond.*

## ทำอะไรได้

- กด Enter ใน Edge ตัวที่คุณใช้อยู่ ตรงเวลาที่ตั้งไว้ ไม่ต้องล็อกอินใหม่
- พิมพ์ข้อความให้เองก่อนเวลา 10 วินาที ภาษาไทยได้ ขึ้นบรรทัดใหม่ได้ (หรือพิมพ์ค้างไว้เองก็ได้)
- แก้นาฬิกาเครื่องที่เดินคลาด ด้วยเวลาจริงจากอินเทอร์เน็ต (NTP)
- วัดดีเลย์เน็ตไปเซิร์ฟเวอร์แชท แล้วกดก่อนเวลาเท่านั้น ข้อความจะถึงเซิร์ฟเวอร์ตรงเวลาพอดี
- ส่งเสร็จ Claude รายงานผลให้เองว่ากดกี่โมง และข้อความถึงประมาณกี่โมง

## ใช้งาน

```
/snipe-dm 00.00                          กด Enter ตอนเที่ยงคืน (ข้อความพิมพ์ค้างไว้เอง)
/snipe-dm "ขอจอง 4 ที่ 20.00 ค่ะ" 00.00   สคริปต์พิมพ์ข้อความให้ แล้วส่งตอนเที่ยงคืน
/snipe-dm 23.59.30                       ตั้งเวลาระดับวินาที
/snipe-dm feedback                       ดูผลรอบล่าสุด
```

หลังสั่ง: สลับไปที่ Edge เปิดแชทให้ถูกคน คลิกในช่องข้อความ แล้วห้ามแตะคอมจนกว่าจะส่ง

## ติดตั้ง

ต้องมี Windows, Microsoft Edge, Python 3.10 ขึ้นไป (ไม่ต้องลงไลบรารีเพิ่ม) และ Claude Code

```
git clone https://github.com/Dawnwing9853/snipe-dm "%USERPROFILE%\.claude\skills\snipe-dm"
```

หรือดาวน์โหลดไฟล์ `SKILL.md` กับ `press_at.py` ไปไว้ใน `~/.claude/skills/snipe-dm/` แล้วเปิด session ใหม่ของ Claude Code

ใช้สคริปต์ตรงๆ โดยไม่ผ่าน Claude ก็ได้:

```
python press_at.py 00.00
python press_at.py 00.00 --msg-file message.txt   # ไฟล์ UTF-8 ที่มีข้อความ
python press_at.py 00.00 --early 0                # ห้ามส่งก่อนเวลาแม้แต่มิลลิวินาทีเดียว
```

## ผลทดสอบ

| เป้าหมาย | กด Enter | ถึงเซิร์ฟเวอร์ (ประมาณ) | ที่ |
|---|---|---|---|
| 23:15:00 | 23:14:59.993 | 23:15:00.001 | Facebook |
| 23:32:00 | 23:31:59.993 | 23:32:00.001 | Instagram (พิมพ์ข้อความให้) |
| 00:00:00 | 23:59:59.993 | 00:00:00.001 | Messenger |

## กันพลาด

- ถ้าหน้าต่างด้านหน้าไม่ใช่ Edge จะไม่พิมพ์และไม่ส่ง
- ถ้าแท็บที่เปิดอยู่ไม่ใช่ Facebook, Messenger หรือ Instagram จะไม่พิมพ์และไม่ส่ง
- Claude ไม่เรียกใช้ skill นี้เอง ต้องพิมพ์คำสั่งเท่านั้น

## ข้อจำกัด

- สคริปต์ไม่รู้ว่าเปิดแชทของใครอยู่ ต้องดูชื่อที่หัวแชทเองก่อนปล่อยมือ
- "ถึงเซิร์ฟเวอร์" เป็นค่าประมาณ ยังไม่รวมเวลาประมวลผลของ Meta อีกไม่กี่สิบมิลลิวินาที ส่วนเวลาที่เครื่องผู้รับเห็นขึ้นกับเน็ตและสถานะเครื่องเขา
- ระหว่างรอห้ามคลิกหน้าต่างอื่น อย่าปล่อยให้จอล็อกหรือคอมเข้า sleep
- การให้โปรแกรมกดแทนในบัญชีส่วนตัวขัดข้อตกลงของ Facebook และ Instagram ใช้ส่งทีละข้อความความเสี่ยงต่ำ แต่ห้ามใช้ส่งรัวๆ หรือส่งหาคนจำนวนมาก ใช้ด้วยความรับผิดชอบของผู้ใช้เอง
